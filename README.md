# OZ Price Analyzer

Локальное Windows-приложение для анализа публичных цен Ozon без Seller API-токена.

## Версия 0.2.0

Интерфейс переработан по логике WB Price Analyzer: отдельные вкладки `Обзор`, `Справочник`, `История отчетов` и `Настройки аналогов`. Настройки больше не занимают главную страницу.

## Основной процесс

1. Загрузите `products.xlsx` или добавьте товары в справочник вручную.
2. Загруженные позиции сохраняются во внутреннем справочнике SQLite и не пропадают после закрытия приложения.
3. Нажмите `Запустить анализ`.
4. Программа получает публичные данные Ozon, характеристики и подбирает аналоги.
5. Результат сохраняется во внутреннюю историю отчетов.
6. Excel создается только по кнопке `Экспорт в Excel` или пакетной выгрузке из истории.

## Входной Excel

Обязательная колонка: `Артикул Ozon`.
Также поддерживаются `Артикул`, `SKU`, `Ozon ID`.

Необязательные колонки:

- `Название`;
- `Штрихкод`;
- `Целевая цена`.

## Главная таблица

На вкладке `Обзор` показываются:

- исходный артикул;
- наименование исходного товара;
- цена исходного товара по выбранному правилу цены;
- пары `Аналог N` / `Цена аналога N`;
- медианная цена выбранного рынка;
- положение `Ниже рынка`, `На уровне рынка`, `Выше рынка`;
- отклонение от медианы рынка в процентах.

Двойной щелчок по названию аналога открывает карточку Ozon. Правая кнопка мыши по аналогу позволяет добавить его в справочник исключений для следующих запусков.

## Настройки подбора аналогов

Настраиваются:

- минимальное общее сходство;
- минимальное совпадение материалов;
- количество аналогов в результате;
- количество проверяемых кандидатов;
- максимальное отклонение габаритов;
- максимальное отклонение веса;
- минимальное число сопоставимых габаритов;
- использование габаритов упаковки как резервного источника;
- строгая принадлежность к той же категории Ozon;
- минимальный рейтинг;
- минимальное количество отзывов;
- веса материалов, габаритов и веса товара в итоговом коэффициенте;
- граница `На уровне рынка`;
- тип цены: автоматическая, без Ozon Карты или с Ozon Картой.

Цена товара специально не участвует в отборе похожих товаров. После прохождения фильтров кандидаты сортируются по сходству, рейтингу и количеству отзывов.

В материальном сравнении текущей мебельной модели используются ЛДСП и пластик. Синонимы ДСП/ЛДСП и распространенные виды пластика нормализуются автоматически.

## Справочник исключений

В `Настройки аналогов` хранится список артикулов Ozon, которые не должны попадать в будущие результаты, даже если формально проходят фильтры. Можно добавить артикул вручную или отправить найденный аналог в исключения прямо из главной таблицы.

## Справочник товаров

Вкладка `Справочник` аккумулирует позиции из ранее загруженных `products.xlsx`. Товары можно добавлять, редактировать, удалять и очищать. Анализ выполняется по всему текущему справочнику.

## История отчетов

Каждый запуск сохраняется локально в `data/ozpriceanalyzer.db`. Старый отчет открывается без повторного запроса Ozon. Отчеты можно переименовывать, удалять и выбирать несколько строк для пакетной Excel-выгрузки.

## Excel-экспорт

Пользовательский экспорт только один — компактная таблица аналогов. В ней один лист `Аналоги` и те же основные столбцы, что на главной странице. Названия исходных товаров и аналогов записываются как гиперссылки.

Папка экспорта задается в настройках приложения.

## Темы

Доступны:

- `Системная` — по умолчанию, на Windows определяется из системного режима приложений;
- `Темная`;
- `Светлая`.

## Ограничения

Используются публичные страницы витрины Ozon, а не официальный Seller API. Ozon может менять HTML-разметку, региональные цены, показывать защитную проверку или ограничивать автоматические запросы. Программа фиксирует такие ситуации в диагностике и продолжает обработку остальных товаров.
