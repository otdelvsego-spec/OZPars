# OZPriceAnalyzer

Локальное Windows-приложение для анализа публичных цен Ozon без Seller API-токена.

## Возможности

- загрузка артикулов из Excel;
- получение названия, бренда, категории, рейтинга и публичных цен Ozon;
- отдельные поля для цены с Ozon Картой и без неё;
- загрузка характеристик со страницы товара `/features/`;
- автоматический поиск аналогов;
- фильтр материалов ЛДСП/пластик с порогом 65%;
- итоговое сходство не ниже 65%;
- история цен;
- целевая цена;
- Excel-отчёт с листами `Результаты`, `Сводка`, `Аналоги`;
- графический интерфейс и Windows `.exe`.

## Установка разработчика

```cmd
pip install -e ".[test,build]"
python -m pytest
```

## Запуск

```cmd
oz-analyzer --input data\products.xlsx --output data\result.xlsx --history data\history.xlsx
```

Для пользователя предназначено оконное приложение `OZPriceAnalyzer.exe`.

## Входной Excel

Обязательная колонка: `Артикул Ozon`.
Также поддерживаются `Артикул`, `SKU`, `Ozon ID`.

Необязательные: `Название`, `Штрихкод`, `Целевая цена`.

## Как выбирается цена

Программа старается определить цену с Ozon Картой и цену без Ozon Карты отдельно. Для истории и сравнения рынка используется текущая минимальная публичная цена; при наличии цены с Ozon Картой она имеет приоритет.

## Аналоги

Поиск идёт по названию товара, названию из Excel, сокращённому названию и категории. Кандидаты проверяются по характеристикам. В материальном сравнении участвуют только ЛДСП и пластик. Минимальное материальное и итоговое сходство — 65%.

## Ограничения

Используются публичные страницы витрины Ozon, а не официальный Seller API. Ozon может менять HTML-разметку, цены для региона, показывать защитную проверку или ограничивать автоматические запросы. Программа распознаёт такие случаи и записывает диагностическое сообщение вместо аварийного завершения всего анализа.
