OZ Price Analyzer 0.2.0
=======================

Локальное Windows-приложение для анализа публичных карточек и аналогов Ozon без Seller API-токена.

ЗАПУСК
1. Распакуйте архив в отдельную папку.
2. Запустите OZPriceAnalyzer.exe.
3. На вкладке «Справочник» загрузите data\products.xlsx либо добавьте товары вручную.
4. При необходимости настройте подбор на вкладке «Настройки аналогов».
5. Нажмите «Запустить анализ» в верхней панели.
6. Результат появится на вкладке «Обзор» и сохранится во внутренней истории.
7. Для Excel нажмите «Экспорт в Excel».

ВХОДНОЙ EXCEL
Обязательная колонка:
- Артикул Ozon

Также принимаются названия:
- Артикул
- SKU
- Ozon ID

Необязательные колонки:
- Название
- Штрихкод
- Целевая цена

СПРАВОЧНИК
Все товары, ранее загруженные из products.xlsx, сохраняются локально в data\ozpriceanalyzer.db.
Новый Excel добавляет новые позиции и обновляет существующие по артикулу.
Анализ выполняется по текущему справочнику.

ОБЗОР
Главная таблица показывает исходный товар и цену, выбранное число аналогов и их цены, медианную цену рынка, положение относительно рынка и отклонение в процентах.
Двойной щелчок по названию открывает карточку Ozon.
Правой кнопкой мыши найденный аналог можно добавить в справочник исключений.

НАСТРОЙКИ АНАЛОГОВ
Можно менять:
- минимальное общее сходство;
- минимальное совпадение материалов;
- количество аналогов;
- число проверяемых кандидатов;
- допустимое отличие габаритов и веса;
- минимальное число сопоставимых габаритов;
- строгую категорию;
- минимальный рейтинг и число отзывов;
- веса материалов, габаритов и веса товара;
- использование габаритов упаковки;
- тип цены Ozon для рыночного сравнения;
- диапазон «На уровне рынка».

Цена не используется для выбора похожих товаров. После фильтров аналоги ранжируются по сходству, рейтингу и количеству отзывов.

ИСКЛЮЧЕНИЯ
На вкладке «Настройки аналогов» есть отдельный справочник артикулов, которые нельзя использовать как аналоги в следующих запусках.

ИСТОРИЯ ОТЧЕТОВ
Каждый запуск сохраняется во внутренней базе. Старые отчеты можно открывать, переименовывать и удалять. Несколько выбранных отчетов можно выгрузить пакетно в папку экспорта.

ЭКСПОРТ
Другие пользовательские Excel-отчеты не создаются автоматически.
Экспорт содержит один лист «Аналоги» с той же компактной структурой, что и главная таблица. Названия товаров работают как ссылки на Ozon.
Папка экспорта задается в настройках. По умолчанию используется папка exports рядом с программой.

ТЕМА
По умолчанию используется системная тема Windows. Также доступны темная и светлая темы.

ФАЙЛЫ
- data\products.xlsx — стартовый шаблон товаров
- data\ozpriceanalyzer.db — локальная база справочника, настроек и истории (создается автоматически)
- exports\ — папка пользовательских Excel-выгрузок

ВАЖНО
Приложение использует публичную витрину Ozon. Это не официальный Seller API.
Ozon может менять HTML-структуру страниц, региональные цены или показывать защитную проверку. Такие случаи фиксируются в диагностике, обработка остальных товаров продолжается.
Интернет-соединение необходимо во время нового анализа. Для просмотра уже сохраненной истории интернет не нужен.
